## 1. 目标

让实现者以外的一方判断「这次改动能不能被接受」：发现作者漏掉的逻辑、边界和回归风险，并且**按风险结束**，不无限往返。要消除的单 Agent 风险：作者盲区；以及现在工程接力的主要毛病，审到第 5 轮、拆单续审。

## 2. 适用 / 禁用

- 适用：L1 及以上的代码、脚本、配置改动，已有 PR 和自测证据。
- 禁用：
  - L0（不改变代码行为的管理文档、记账类改动）：只做机械检查，不送审（agent-kit《工程流程》第 8 节第 3 条）；
  - 方向问题（问题定义、路线、架构前提）→ 转 [MA-01](MA-01-thinking-review.md)；
  - 只缺可运行证据、不缺判断 → 先补测试（或等 MA-03 成立后转 MA-03），不靠多审一轮补证据。
- 与 MA-03（候选）的分界：MA-02 回答「能不能接受」，产出审查意见和接受/升级决定；MA-03 回答「关键行为有没有被独立证实」，产出可复现的运行证据。MA-02 可以调用独立验证作为证据，但不默认绑定 Codex。

## 4. 输入与交接物（接口）

- 送审前先定风险级（L0–L3，定义沿用 DT-ORC ARCHITECTURE 的风险分级），写进送审包第一行，并在调用 `relay_to_chatgpt` 时填 `risk`（L1–L3；L0 驿窗拒收）。
- 送审包：驿窗「六项」，即任务名与目标、改了什么和为什么、分支与 PR 链接、diff 或摘要、希望重点看哪里、按严重程度列问题。另外要绑定 `repo / base_sha / head_sha`，被审的 PR 链接要是送审包里第一个出现的 PR 链接（驿窗靠它跨会话累计轮数，不用手写原单）。
- 回信：按严重程度（P0–P3）列问题。审查语义有四档：通过、返修、证据不足暂停、决策升级。驿窗结论仍是「通过 / 需修改」二态，四档写在回信倒数第二行（postpane#233）：
  - 倒数第二行「审查出口：通过 / 返修 / 证据不足暂停 / 决策升级」，最后一行「结论：通过 / 需修改」，通过配通过，其余配需修改；
  - 证据不足暂停：驿窗转回 Claude 并停自动往返，Claude 补了证据再送就自动续上，那一次不计轮数；决策升级：转回 Claude 并交常浩；出口与结论对不上：不转回，交常浩；
  - 没写审查出口这一行：只看结论，按返修处理。

## 5. 审查预算与停止条件（常浩 2026-11-07 批准）

| 级别 | 自动审查预算 | 额外要求 |
|---|---|---|
| L0 | 0 轮 | 机械检查 |
| L1 | 默认 1 轮 | 自测和增量证据 |
| L2 | 最多 2 轮 | 自测、回归与独立主审 |
| L3 | 最多 2 轮 | 前置风险分析、必要的独立验证、常浩动作授权 |

- 轮数从第一次正式送审起算。**换 head SHA、换工单编号、另开一单都不重置**，续审要关联原单。
- 停止自动往返，转重新设计、补证据或常浩裁决的情形：达到预算；同一问题修复后重复出现；关键证据不足；出现需要改原方案的问题。
- 常浩授权的专项续审要写明目标、次数和理由，并记进第 7 节运行记录。
- 只剩 P2/P3、没有 P0/P1 时，可以按「通过附建议」收口：补改后在 PR 上写「补改未复审」，不再开一轮（参照 SBX-8）。
- 审查通过不等于合并、部署或上线授权。

**落地边界**：这是统一解释，不直接改写其他项目已生效的规则。现行三处规则与本契约的对应如下，实际改动各自开单：

| 同一份送审 2 轮仍不过，停下由常浩拍板 | agent-kit《工程流程》第 8 节第 3 条 | 默认升级节点 |
| 每份最多 2 轮，L1 默认 1 轮 | DT-ORC ARCHITECTURE 6.4 | 自动循环预算 |
| ~~工程接力固定 2 轮，只认通过/需修改~~ | 驿窗 `relay_to_chatgpt` | **已对齐**（postpane#233，`fb62a6a`）：按 `risk` 设预算、同一 PR 跨会话累计、预算用完要 `extra` 授权、L1 需修改转回收口、审查出口四档 |

## 8. 人工必须决定的事项

- 合并授权（常浩说「合并」，或按各项目已批准的自动合并规则）。
- 超预算后的去向：收缩范围、重新设计、补证据、换审查手段，或授权一次有边界的专项续审。
- L3 的动作授权与风险接受。

## 9. 价值评估

- 关键发现：经核实、作者原本没发现的 P0/P1。P2/P3 和措辞建议不算关键发现。
- 每次运行记：风险级、轮次、P0/P1 数、是否超预算、是否拆单、常浩介入次数、从第一次送审到收口的时长。
- 反向信号：同级任务的平均轮数没有下降；拆单重置轮数再次出现；L0 改动被送审。
